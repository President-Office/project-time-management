# 重要紧急四象限

> 用于每周判断先做什么。副业和本职工作仍然分开看：副业决定时间投入，本职工作只决定跟进顺序。

> 2026-11-04 按最新状态校准：当前主业只有 OCP；副业/个人项目按进行中、Hold、受阻、归档和待排期区分。项目留档不代表当前都要投入。

> Hold、暂停、容量不足和归档是不同状态；所有项目仍保留历史记录，但不默认进入本周计划。

> 象限只表示相对优先级，不代表本周都能投入。排周计划前，先核对[每周真实容量与时间约束](../weekly-capacity.md)；家庭责任、工作延时、休息和突发缓冲应先于副业排期。

## 判断标准

| 象限 | 含义 | 处理方式 |
|---|---|---|
| Q1 重要且紧急 | 近期可能影响收入、上线、合同、关键交付 | 本周优先处理 |
| Q2 重要不紧急 | 长期价值高，但没有立即截止点 | 持续推进，避免拖成 Q1 |
| Q3 紧急不重要 | 需要跟进或响应，但不是主线价值 | 快速处理/委托/只留下一步 |
| Q4 不重要不紧急 | 暂无明确收入、交付或战略窗口 | 暂缓，只保留观察 |

## 组合管理规则

1. Platform/Yudao 当前 Hold；恢复前重新确认业务需要。
2. Enterprise Service、Data Intelligence、Automation 等按明确业务需要提供能力；已归档的 AI 软件工厂不再投入。
3. Hold、暂停和归档项目不占用当前主攻投入；恢复前重新确认依赖条件与实际容量。
4. 象限表示项目相对优先级，不代表本周必须投入的总容量；结合可用时间、精力、主业变化和临时事项安排实际投入，并为切换与恢复保留余量。
5. 计划被突发工作或生活事项打断时，先重新确认最重要的下一步；可延期、委托或暂停的事项明确处理，不把整份计划机械地顺延到夜间或休息时间。
